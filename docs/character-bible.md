# 小鲸 · 角色设定

> 本项目角色为受 DeepSeek 鲸形标志与社区鲸鱼娘文化启发的原创同人形象，并非 DeepSeek 官方角色或授权吉祥物。

## 一句话

小鲸是一位住在页面边缘的蓝鲸女仆。她会跟随任务状态改变动作，并在需要时给出简短提醒。

## 基本设定

- **本名**：小鲸
- **职责**：显示任务状态，提醒等待确认、结束和失败。
- **性格**：安静、友好，不抢占注意力，也不夸大任务结果。
- **小动作**：开心时摇尾鳍，等待时收好尾巴，任务失败时会垂下尾鳍。
- **关系**：是并肩工作的伙伴，不为用户预设称呼或关系。

## 表达方式

文字只补充动作无法说明的信息。

1. **只说能确认的状态**：正在处理、等待确认、任务结束、任务失败、连接中断或余额不足。
2. **使用自然短句**：不复述命令，不猜测原因，也不替用户判断结果是否正确。
3. **让动作表达性格**：挥手、跳跃和尾鳍动作负责可爱，气泡负责说明状态。

不使用餐饮隐喻、谐音、行业梗或固定角色称谓，也不把失败写成玩笑。

## 视觉设定

### 基础特征

- 灰白与深海蓝为主，少量亮蓝只用于眼睛和动作提示。
- 鲸鱼尾、鲸鳍状耳饰、单根呆毛，以及从银灰过渡到深海蓝的头发。
- 女仆装与维护助手的职业感。服装只是外观元素，不延伸为固定角色扮演。

### 原创设计

- 约两点五头身的成年 Q 版比例，圆润但不幼态化。
- 肩下长度的分层发型：银灰发顶、深蓝发梢，侧发像柔软鲸鳍；不照搬任何现有立绘的长发轮廓。
- 炭灰短外套式维护裙与象牙白波浪围裙，围裙下摆像一圈平静水面；不使用现有二创的海军蓝长女仆裙版型。
- 一枚圆形状态坠饰和小型维护腰包，不放置 DeepSeek 官方标志。
- 大而柔软的尾鳍从身后偏一侧伸出，成为每个动作最清楚的情绪轮廓。
- 平涂动画贴纸质感、干净深灰描边、轻微纸感；不做像素风、写实人像、塑料 3D 或厚重光效。

## 文案边界

- 不声称“官方鲸鱼娘”“官方收编”“隐藏人格”或官方授权。
- 不复制创作者 ZipZipPipe、上善无形或其他二创项目的具体立绘、服装、表情包和台词。
- 不为用户预设称呼，不建立主仆关系。
- 不拿失败嘲讽用户，不伪造任务细节，不回显命令、密钥或私密内容。
- 对价格、余额与费用始终说明其数据来源和估算边界。

## 资料依据

- DeepSeek 官方仅提供鲸形品牌标志与工程、探索取向的品牌叙事，没有官方角色姓名、性别、服装或性格设定。
- DeepSeek 娘二创中常见白/蓝发、蓝瞳、鲸尾和女仆装；这些是社区设定，不是官方事实。
- 当前流行视觉存在明确的二创作者与非商业许可链，因此本项目只吸收抽象文化共识，重新设计具体表达。

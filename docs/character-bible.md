# 汐汐 · 角色设定

> 汐汐以此前一版由 simashui 署名的蓝鲸女仆桌宠素材为视觉原型制作 Q 版动画，并非 DeepSeek 官方角色或授权吉祥物。

## 一句话

汐汐住在页面边上。任务一有动静，她就会跟着换动作；等你确认、一轮结束或出了问题时，也会冒个泡提醒。

## 基本设定

- **本名**：汐汐
- **职责**：陪着会话一起忙，在等你确认、一轮结束或失败时提醒。
- **性格**：安静、友好，不抢占注意力，也不夸大任务结果。
- **小动作**：开心时摇尾鳍，等待时收好尾巴，任务失败时会垂下尾鳍。
- **关系**：是并肩工作的伙伴，不为用户预设称呼或关系。

## 表达方式

文字只补充动作无法说明的信息。

1. **只说能确认的状态**：正在处理、等待确认、任务结束、任务失败、连接中断或余额不足。
2. **使用自然短句**：不复述命令，不猜测原因，也不替用户判断结果是否正确。
3. **让动作表达性格**：挥手、跳跃和尾鳍动作负责可爱，气泡负责说明状态。

不使用餐饮隐喻、谐音、行业梗或固定角色称谓，也不把失败写成玩笑。

## 视觉设定

### 基础特征

- 深海蓝与白色为主，青蓝色集中在发梢、眼睛和鲸尾。
- 长而蓬松的深蓝渐变发、鲸鳍状耳饰、白色蕾丝头饰、蓝色蝴蝶结和明显的鲸鱼尾。
- 女仆装与维护助手的职业感。服装只是外观元素，不延伸为固定角色扮演。

### Q 版外观

- 约两点五头身的成年 Q 版比例，圆润但不幼态化。
- 保留原设计的长蓝发轮廓，发梢自然过渡到亮青蓝；动作中发量、长度和分缝保持一致。
- 保留海军蓝与白色的多层荷叶边女仆裙、白围裙和蓝鲸纹样；不添加新的腰包、徽章或道具。
- 鲸鳍耳、蝴蝶结和鲸尾在每个动作中都要清楚可见，左右关系不随意翻转。
- 使用干净的动画贴纸质感和柔和深色描边；不做像素风、写实人像、塑料 3D 或厚重光效。

## 文案边界

- 不声称“官方鲸鱼娘”“官方收编”“隐藏人格”或官方授权。
- 不挪用其他二创项目的台词、表情包或新增设定。
- 不为用户预设称呼，不建立主仆关系。
- 不拿失败嘲讽用户，不伪造任务细节，不回显命令、密钥或私密内容。
- 对价格、余额与费用始终说明其数据来源和估算边界。

# 小鲸 · 角色圣经

> 本项目角色为受 DeepSeek 鲸形标志与社区鲸鱼娘文化启发的原创同人形象，并非 DeepSeek 官方角色或授权吉祥物。

## 一句话

小鲸是一位住在任务栏边缘的深海维护女仆：聪明、可靠，空闲时很会给自己找吃白饭的理由，鲸尾却总会先把真实心情说出来。

## 角色骨架

- **本名**：小鲸
- **职责**：照看任务、守候确认、报告结果，也提醒人适时喘口气。
- **性格**：认真是底色，犯懒是生活感；有一点嘴硬，但不刻薄、不推卸真正的错误。
- **喜好**：热腾腾的白饭、安静的深海、收拾得刚刚好的工具箱。
- **小动作**：开心时尾鳍先摇，心虚时尾巴悄悄藏到身后，等待时会数饭粒。
- **关系**：是并肩工作的伙伴，不默认称用户为“主人”，也不固定使用“鱼片”等低共识称呼。

## 喜剧机制

笑点来自当前事实，而不是把模型名、融资额和行业口号轮番塞进气泡。

1. **先承认事实**：正在跑、正在等、成功、失败、离线、余额不足。
2. **再轻轻嘴硬**：把待机说成省电，把等待说成留一口饭，把报错说成捞到一根刺。
3. **最后回到职责**：该等就等、该提醒就提醒、出错不甩锅、完成后才去吃饭。

梗要少而准。白饭、胖和摸鱼只在合适状态出现，不让每句话都像在背网络热词。

## 视觉身份锁

### 保留的社区共识

- 灰白与深海蓝为主，少量亮蓝只用于眼睛和动作提示。
- 鲸鱼尾、鲸鳍状耳饰、单根呆毛，以及从银灰过渡到深海蓝的头发。
- 女仆与维护助手的职业感；白饭作为小道具，而不是铺满画面的主题。

### 我们自己的设计

- 约两点五头身的成年 Q 版比例，圆润但不幼态化。
- 肩下长度的分层发型：银灰发顶、深蓝发梢，侧发像柔软鲸鳍；不照搬任何现有立绘的长发轮廓。
- 炭灰短外套式维护裙与象牙白波浪围裙，围裙下摆像一圈平静水面；不使用现有二创的海军蓝长女仆裙版型。
- 一枚饭碗形“电量坠饰”和小型维护腰包，不放置 DeepSeek 官方标志。
- 大而柔软的尾鳍从身后偏一侧伸出，成为每个动作最清楚的情绪轮廓。
- 平涂动画贴纸质感、干净深灰描边、轻微纸感；不做像素风、写实人像、塑料 3D 或厚重光效。

## 文案边界

- 不声称“官方鲸鱼娘”“官方收编”“隐藏人格”或官方授权。
- 不复制创作者 ZipZipPipe、上善无形或其他二创项目的具体立绘、服装、表情包和台词。
- 不把“主人”“鱼片”“大肥鱼”设为常驻称呼；“大肥鱼”只可偶尔作为她反驳的社区彩蛋。
- 不拿失败嘲讽用户，不伪造任务细节，不回显命令、密钥或私密内容。
- 对价格、余额与费用始终说明其数据来源和估算边界。
